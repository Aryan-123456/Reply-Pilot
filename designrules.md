### Design System & Conversion Rules

Follow modern SaaS UI/UX best practices throughout the entire landing page.

**Typography**

* Use premium, distinctive fonts (avoid generic defaults like Poppins or Inter unless paired thoughtfully).
* Build a consistent type scale using a Major Third ratio.
* Body text: 16px with 1.5 line height.
* Tighten letter spacing on headings for a premium appearance.
* Use a clear typography hierarchy with H1, H2, H3, body, and caption styles.

**Layout**

* Use a responsive 12-column desktop grid, 8-column tablet grid, and 4-column mobile grid.
* Follow an 8-point spacing system (8, 16, 24, 32, 48, 64, 96px).
* Create strong visual hierarchy using proximity, size, contrast, and alignment.
* Keep sections spacious with generous whitespace to achieve a premium SaaS feel.

**Color System**

* Follow the 60-30-10 color rule:

  * 60% neutral backgrounds and text
  * 30% supporting surfaces and cards
  * 10% accent color for CTAs and highlights
* Create depth using opacity variations instead of introducing unnecessary colors.
* Ensure WCAG-compliant contrast ratios for accessibility.

**Components**

* Use large rounded cards with subtle borders and soft shadows.
* Include smooth hover states and micro-interactions.
* Buttons should have clear hover, active, and focus states.
* Use high-quality icons and realistic dashboard mockups instead of generic illustrations.
* Apply subtle gradients only where they enhance emphasis.

**Conversion Optimization**

* Every section should move the visitor toward a single goal: **Start Free**.
* Keep the primary CTA visible in the navigation, hero, after key sections, pricing, and final CTA.
* Use benefit-first messaging before introducing features.
* Reinforce trust with testimonials, customer logos, usage statistics, security indicators, and guarantees.
* Show the product visually instead of explaining it with long paragraphs.
* Minimize friction by emphasizing fast setup, automation, and ease of use.

**Responsive Design**

* Mobile-first implementation.
* Optimize spacing, typography, and button sizes for touch devices.
* Maintain consistent hierarchy across all screen sizes.

**Performance**

* Fast loading with optimized assets.
* Semantic HTML.
* SEO-friendly structure.
* Accessible components.
* Clean, maintainable code.

The final result should feel comparable to landing pages from Stripe, Linear, Vercel, Notion, and Framer: premium, modern, trustworthy, minimal, and highly conversion-focused.
